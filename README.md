# Public Archive: Exploratorio Desarrollo Web

This is a public archive of all coursework and projects recovered from school servers, dating back to 2024.

## Structure
- **01_web_dev**: Web development projects, including the original "webproject1s" archive.
- **02_psint**: Logic and algorithm projects developed in PSeInt.
- **03_arduino**: Arduino sketches for hardware projects.
- **04_spreadsheets**: Coursework spreadsheets (cotidianos).

All content is preserved for historical and educational purposes.
